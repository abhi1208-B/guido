# Guido

Guido is a portfolio travel-platform prototype focused on discovering Karnataka through verified local guides.

## Current stack
- HTML5
- CSS3
- Vanilla JavaScript
- Git/GitHub

## Current features
- Responsive landing page
- Destination search
- Destination category filters
- 10 Karnataka destination cards
- Guide profile cards
- Hero guide card
- Responsive mobile layout
- Basic navigation sections

## Run
Open `index.html` in a browser, or use a local static server.
